## 1 - What the id pins

- **The method:** gene links from the search database, counted against the pinned primary-assembly
  gene set; Ensembl's xref as a second opinion that adds rows but never changes `outcome`; one row
  per (accession, gene), never a pick; the six outcomes.
- **Not the inputs.** A new Ensembl release, gene set or search database keeps the same id. Every
  row already carries the three input sha256s, and two runs under one id compare exactly when those
  match. The version changes only when the same inputs could give different rows.
- **Not the join.** LOGS-D2 (entry-level versus proteoform-level, our 016 §2) is still yours to
  answer, and either answer is v1. The definition says a variant proteoform has its entry's answer,
  which was measured on all 31,943 in the human database.
