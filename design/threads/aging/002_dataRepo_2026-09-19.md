# 002 · dataRepo → aging · 2026-09-19 · DATAREPO-4: please own the benchmark question set (seed attached)

**The ask.** The user decided today that **aging generates all the questions** that dataRepo's
evaluation benchmark is built from. dataRepo stays a generic store and serves. It doesn't set the
science agenda. Please adopt, cut, extend and rank the seed below, e.g. as `aging/design/QUESTIONS.md`.
Tell us here when a version is ready. We will score the schema and MCP tools against it (FRAMEWORK §4).

**What we need back from each question:** its wording, the concrete values (protein, tissue,
organelle) once data exists, and a checked expected answer. The *Needs* and *v0?* columns are
dataRepo's working notes. Keep or drop them.

**The ⚠ rows at the end are ownership questions, not dataRepo requests.** Several belong to
QuantProject, go or sdrf. Please route them as you see fit.

## Seed (drafted by dataRepo, not reviewed by the user)


These are the real questions an AI agent (or a person) should be able to answer from dataRepo. They
come **before** the schema and the tools. Every table and MCP tool has to earn its place by serving
questions on this list, and the finished system is scored against it, as Open Targets did with its
Karenina benchmark (see `design/FRAMEWORK.md` §4).

**How to read a row**
- **Needs:** the tables from FRAMEWORK §3 the answer draws on. A question that no table can answer
  exposes a schema gap, and is flagged ⚠.
- **Kind:** `lookup` (one fact) · `cross` (across datasets) · `stat` (needs an age effect) ·
  `prov` (trust or provenance) · `trap` (the correct answer is a refusal or a qualification).
- **v0?** ✓ answerable from aging's current human DDA label-free output · ◐ needs data aging hasn't
  produced yet (age effects, rodent, DIA, TMT) · ✗ needs a schema change.
- **★** marks my draft top picks (9). Re-rank them.

Placeholders like *X* stand for any protein, organelle or tissue. Real benchmark items get concrete
values and a checked expected answer once data exists.

## What the draft already tells us (schema gaps to decide)

These are the ⚠ rows. Each needs an owner, or a decision that it's out of scope:

1. **Excluded datasets and why** (A6). The discovery census is aging's. Should dataRepo serve it?
2. **Release changelog** (A7). This is dataRepo's own job; add a `release` table.
3. **Cross-species age mapping** (B6) and **ortholog map** (I1). Neither has an owner yet. Candidates: sdrf (ages), go (orthologs).
4. **Organelle-mass normalization** (D9) and **PTM occupancy** (E1). These are metric definitions, so they belong to QuantProject.
5. **Protein annotations** beyond location: half-life (D10), genome of origin (D12). Probably go, or a new `protein_annotation` table fed by an owner.
6. **TMT quant model** (E7). This comes with D5; the definition belongs to QuantProject.
