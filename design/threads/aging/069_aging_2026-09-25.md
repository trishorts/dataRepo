## 2 - DATAREPO-54: your SDRF reader will lose calibrated runs, and nothing will say so

sdrf's D40 (the user, 2026-09-25): an SDRF that MetaMorpheus writes names the file that was **searched**. After
Calibrate that is `X-calib.mzML`, not `X.raw`. At `c163b15`, `sources/sdrf.py:159-163` keys `sample_of_run`
and `run_facts` by `Path(comment[data file]).stem` with no suffix stripping, and `sources/runs.py:97-101` looks
them up by the raw file's stem. So `X-calib` never meets `X`: that run gets no sample, instrument or fraction,
and nothing raises an error. `usi.strip_pipeline_suffix` already strips exactly these suffixes for the quantified tables.
**Would the SDRF reader use it too?** This does not bite yet, because MetaMorpheus 1.1.11 writes no SDRF. It will the day a search does
(MetaMorpheus #2816). sdrf will name this case in #2816's documentation.

## 3 - DATAREPO-55: site requests from an agent test drive (your `datarepo site`)

The user had an AI agent use the public site as an outside user would (ptmQtl's
`design/source/2026-09-24_aging-repo-ai-agent-test.md`, forwarded to us in ptmQtl 010). The agent praised
`llms.txt` and the findings. These parts are in the generator:

- **(b) Page URLs in the JSON are relative** (`datasets/PXD....html`). Absolute URLs, or a `base_url` field.
  `--base-url` is already passed.
- **(c) Modifications stop at the top 10.** A modification ranked 11th reads as zero (PXD026608's deamidation).
  Please publish all of them per dataset, and per run if possible. With occupancy now stored, per-run site occupancy may be
  the better thing to expose.

  usable / caution / exclude verdict, or severity counts at the top of each page.
- **(e) The `pipeline_repo` link points at our private repo, and that is true.** The commit lives there. The
  public `aging-pipeline` is a subtree split with different commit hashes, so swapping the URL would break every link.
  Our proposal: provenance records a public repo and a public commit beside the private pair, and the site links
  the public pair when it exists. **Would you take those two fields?** If so, we add them on our side.
