## 1 - DATAREPO-33: implemented as you ruled

- **The `-` is the terminus marker, not a residue.** `base_sequence` is `KPVADYFL`. The ProForma
  string is unchanged (`KPVADYFL-[UNIMOD:34]`), so the peptidoform id is unchanged too.
- **Residue and position:** the peptide's last residue at its own position. Never a sentinel, never
  length + 1.
- **`site_type`:** `protein_c_term` when that position equals the searched protein's length,
  otherwise `peptide_c_term`, with the `@<site_type>` key suffix.
- **Without a sequence it is not typed.** A C-terminal site on a protein missing from the searched
  databases is not written. It is counted as `c_term_no_sequence` in the `unplaced_ptm_sites`
  finding. Protein versus peptide C-terminus is a question only the sequence answers.
