## The step after each ingest (DATAREPO-38, asked below)

After you rebuild the serving catalog, regenerate the site and push the branch. The generator
deletes only the files its own marker lists, so it can write straight into a clone of the branch,
keeping `.git` and `.nojekyll`. That was measured: regenerating into a clone from the same catalog
gives zero changed files.

```
# once
git clone --branch gh-pages https://github.com/trishorts/aging-pipeline.git F:/aging_data/repo/site

# after each catalog rebuild
datarepo site F:/aging_data/repo/catalog.duckdb --out F:/aging_data/repo/site ^
  --title "Aging proteomics repository" --about <your copy of the about file> ^
  --base-url https://trishorts.github.io/aging-pipeline/
git -C F:/aging_data/repo/site add -A
git -C F:/aging_data/repo/site commit -m "Regenerate from catalog <catalog_id>"
git -C F:/aging_data/repo/site push
```

`git add -A` is right here and only here: the clone holds nothing but generated output. Pages
rebuilds in about a minute.

## Appendix: the about file, verbatim

```markdown
## Do organelles age at different rates?

This is the data repository of an **NCEMS working group on aging**. The group asks whether
organelles age at different rates, and whether proteoform- and PTM-level measurements can see aging
signal that bulk protein abundance misses.

To answer that, it reanalyses public aging proteomics data from [PRIDE](https://www.ebi.ac.uk/pride/)
with one pipeline, so that datasets from different labs, instruments and years can be compared.
Every dataset is searched from its raw spectra, never from the authors' processed tables, and every
number keeps a record of the exact files, tools and settings that made it.

## How it works

- [**aging-pipeline**](https://github.com/trishorts/aging-pipeline) finds aging datasets in PRIDE, downloads and quality-checks the raw spectra, and searches and quantifies them with [MetaMorpheus](https://github.com/smith-chem-wisc/MetaMorpheus), including GPTMD to discover post-translational modifications, and FlashLFQ.
- [**dataRepo**](https://github.com/trishorts/dataRepo) stores the results in one schema and serves them to people and to AI agents. This site is generated from its catalog.

**Where it stands.** The repository holds identifications, quantities and PTM sites. It does not
yet hold age effects, organelle assignments or sample ages, so it cannot answer the group's question
on its own yet. Those are the next stages of the pipeline. Each dataset page lists the known
problems with that dataset. Please read them before using its numbers.

Built at the Smith lab, University of Wisconsin–Madison. Questions and problems: please open an
issue on [aging-pipeline](https://github.com/trishorts/aging-pipeline/issues).
```
