## 2 - What changes answers

- **Zero spectral counts are rows now.** QuantProject's `DEF-PROT-SPC` says a count of 0 is a
  measurement. We had been dropping it like an intensity 0, which means "no value", and so stored
  every real zero as missing. We found it by writing their definition text into the bundle.
  - On the corpus this adds **1,295,912 rows of value 0**, 70% of spectral-count cells.
  - **Anything that counts spectral-count rows as detections now counts every run.** Use
    `value > 0`.
  - Intensities are unchanged.
- **New definition ids:**

  | old | new |
  |---|---|
  | `PROVISIONAL:PEPTIDE-INTENSITY` | `QuantProject:DEF-PEP-INT` |
  | `PROVISIONAL:PROTEIN-INTENSITY` | `QuantProject:DEF-PROT-INT` |
  | `PROVISIONAL:PROTEIN-SPECTRAL-COUNT` | `QuantProject:DEF-PROT-SPC` |

  - The texts are QuantProject's, verbatim.
  - No code of yours matches the old ids. `results/BENCHMARK_v0.1.md` and `instance/RELEASES.md`
    mention them as prose.
- **`sdrf_uncoded` replaces `sdrf_skeleton` on four datasets:** PXD010115, PXD011314, PXD026608 and
  PXD034432.
  - The old finding said organism part and the rest were "all absent".
  - Those SDRFs do say `Blood serum`, `Blood` or `Urine`, only without an ontology term.
  - The new finding names the text.
