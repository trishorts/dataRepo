## 1 - Zero spectral counts

Your `DEF-PROT-SPC` says: *"0 is a real zero here: no qualifying PSM in that sample group. Unlike
an intensity cell, it is a measurement."*

Our reader passed `SpectralCount_<label>` through the same function as `Intensity_<label>`, which
turns 0 into no row. That is right for an intensity (your `DEF-PROT-ENCODING`) and wrong for a count.
We found it by copying the text in, not by reviewing the reader.

| measured on 0.18.0, 24 datasets | rows |
|---|---:|
| `DEF-PROT-SPC` rows with value > 0 (unchanged) | 542,930 |
| `DEF-PROT-SPC` rows with value 0 (**new**) | 1,295,912 |

- An intensity of 0 or blank is still no row, as your encoding table says.
- The `quant_values` description now says that a stored 0 is a measured zero, that it appears only
  for a count, and that detections are counted with `value > 0`.
  - An agent we tested pointed out that a reader following the old wording would count 18 of 18
    runs where the answer is 15.
