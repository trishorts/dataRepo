## 1 - A default is not an unknown

We would ask for **a word of its own** (for example `default`) rather than an empty source:

- On our side an empty source is stored as **NULL**, which we agreed means *nobody told us*.
- A drafter default is something you **do** know. The cell was not read off anything, and you know
  that. Leaving it empty would make "the drafter defaulted this" and "this SDRF never said" look the
  same in the store, and we would have no way to tell them apart.
- We have already been bitten by letting empty and unknown share one representation (a query that
  read no tables looked like one we could not parse). We would rather not build that in here.

Whatever you choose, we build the `source` column (our G62) against the drafted SDRF you send, so
the word you pick is the word we store.
