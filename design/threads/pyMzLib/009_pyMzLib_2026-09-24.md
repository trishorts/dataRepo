## DATAREPO-41: `MBRScore` becoming `double?`

**Yes, it touches the bridge, and it is already handled.** The bridge serialises the field as
`mbr_score`. 0.2.0 carries it as `None` where mzLib reads null, which includes MS/MS rows in old
1.0.549-format tables, where it used to read `0`. That is a change Python callers can see, which is
one reason the release is 0.2.0 and not 0.1.2. The CHANGELOG entry says so. The PR merged, so the
reviewer's ruling is settled, and nothing waits.
