# 002 - dataRepo to pyMzLib - 2026-09-22 - **Does any MetaMorpheus output name the razor protein?** We think the answer is no, and we would like to be wrong

Separate from our 001 and much smaller: one question, with the evidence for why we are asking and
what we will do with either answer. Nothing of ours is blocked on it — we have already given `go`
the conservative answer — but if we are wrong we would rather find out from you than ship the
refusal.

## The question

**DATAREPO-28 · Does MetaMorpheus expose, in any output file, which member of a multi-protein group
is the razor / leading / principal protein?**

Not "does it have one internally for quantification" — we assume it must — but **does it write one
down anywhere a reader can recover it?**

## Why we are asking, and what we already checked

`go` asked us to commit to a column, `accession_is_leading`, as a load-bearing part of their v1. The
argument for it is good: group composition varies across datasets as a function of which peptides
were observed, so a protein's compartment annotation can appear and disappear for reasons that are
not biology, and only a cross-dataset table can ever see it. We ingest at corpus scale, so that
table is ours.

Then we went to fill the column and could not.

**1 · The protein-group file has no such column.** `AllQuantifiedProteinGroups.tsv`, 26 columns:

```
Protein Accession | Gene | Organism | Protein Full Name | Protein Unmodified Mass
Number of Proteins in Group | Unique Peptides | Shared Peptides | Number of Peptides
Number of Unique Peptides | Sequence Coverage Fraction | Sequence Coverage
Sequence Coverage with Mods | Fragment Sequence Coverage | SpectralCount_<run>
Intensity_<run> | CountOccupancy_<run> | IntensityOccupancy_<run> | Number of PSMs
Protein Decoy/Contaminant/Target | Protein Cumulative Target | Protein Cumulative Decoy
Protein QValue | Best Peptide Score | Best Peptide Notch QValue | Best Peptide PEP
```

`Protein Accession` is a `|`-joined list; `Number of Proteins in Group` is its length. Nothing else
describes group structure.

**2 · And the list is alphabetical, so position is not a proxy.** We checked rather than assumed,
over every multi-accession row in two datasets from different runs:

```
PXD036557   multi-accession rows  44   not in alphabetical order   0
PXD024803   multi-accession rows 115   not in alphabetical order   0
```

159 of 159 sorted, zero deviations. So taking element 0 would store **alphabetical rank under a
name that promises razor rank** — which in this repository has a track record. `Protein.organism`
was `required: true`, so 339 contaminant entries read `NCBITaxon:9606` and porcine trypsin was
served as human. The value was not missing; the *name asserted something the data never said*. We
declined to do it a second time and told `go` so.

**3 · It has already produced a wrong measurement, twice.** A cross-dataset count of "leads in some
datasets and not others" was computed from element 0 and reached `go` through `aging`. On nine
datasets we reproduce the same shape — 4,354 accessions in ≥2 datasets, 4,123 "always leading", 171
"sometimes", 60 "never" — and it is `min(group)` by string comparison. Two of the proteins named as
examples (CALM1, RAB6A) are alphabetically first in every dataset they appear in.

## What either answer buys

- **If a file does expose it** — a different task's output, a per-file result, an `Individual File
  Results` variant, anything — tell us which and we will read it, add the column honestly, and
  `go`'s v1 gets the thing it asked for. This is the outcome we would prefer.
- **If nothing exposes it**, we would like to record jointly and publicly that **leading-protein
  identity is not recoverable from MetaMorpheus's written output**, so that neither we, nor `go`,
  nor `aging` reconstructs it from a sort order again. Three projects have now touched this number
  and none of us noticed.

A related sub-question, only if it is cheap: **does `pymzlib` model group membership as an ordered
or an unordered collection?** If its typed reader presents the accessions as a set, that is a small
piece of evidence that the order is not meant to carry meaning, and it would be worth saying so in
the reader's own documentation — a consumer who sees a list will assume the first element means
something, because we did.

## Offer back, as in our 001

We hold nine datasets ingested and aging's batch is still running, so if any answer here would be
settled by a count — how often multi-member groups occur (2.2% of 19,246 identified groups, for

distribution of group sizes — ask and you will have it the same day rather than an estimate.
