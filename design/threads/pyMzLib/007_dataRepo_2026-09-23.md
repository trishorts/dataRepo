| D, [#1346](https://github.com/smith-chem-wisc/mzLib/pull/1346) | `ebdfa790` | `SpectrumMatchFromTsv.ProForma`: a **blank** `ProForma` cell is now computed from `Full Sequence`, the same as an absent column |

## 1 - PR E: `MBRScore` is nullable, and blank means null

- **`MBRScore` is `double?`.** Our 005 §2 kept it `double` to avoid a public type change, and
  flagged the choice. The reviewer asked for `double?`, so a projected `mbr_score` field is now
  optional wherever the bridge carries it.
- **One converter for all three columns.** A new `DashOrBlankToNullDoubleConverter` (internal)
  reads `-` or blank as null and writes null as blank. A cell that is neither a number nor
  `-`/blank still throws. It covers `MBRScore`, `PipQValue` and `PipPep`.
- **We did not use the existing `DashToNullOrDoubleConverter`, which the reviewer suggested.** It
  reads a BLANK cell as 0.0, through its `TryParse` fallback. The PIP columns are blank on every
  MS/MS peak, so every MS/MS peak would have read PIP Q-Value 0, which is the best possible value.
  Worth knowing if any binding maps a mzLib field through that converter.
- **Behaviour change for old files.** 1.0.549-format tables write `MBR Score` blank on MS/MS rows.
  Those rows read `MBRScore` as **null where they read 0 before**. That is the intended fix, but it
  changes what an existing caller sees. We flagged it on the PR as the reviewer's call, and they
  have not answered yet.
- **Tests:** all of `Test.FileReadingTests` passes, 1,250/1,250.

## 2 - PR D: a blank cell counts as absent

Before, a present but blank `ProForma` cell was taken as the file's value: the row read null and
each split-out candidate of a disambiguated row inherited that null. Only a non-blank cell counts
now. Nothing else changed. The three-way difference from our `proforma.py` in 005 §1 still stands.

**Evidence for not adding a catch-all.** The reviewer asked whether the getter could throw on real
data. We converted every distinct `Full Sequence` in aging's 21 real searches, using a temporary
test that was not committed:

| rows | distinct | converted | null (ambiguous, by design) | null (other) | thrown |
|---|---|---|---|---|---|
| 8,361,580 | 1,315,772 | 1,217,630 | 98,142 | 0 | 0 |

The PR reply declines a catch-all on that evidence. The pushed commit message says 21 tests. The
real count is 20: the 21st was the temporary probe. The PR comment was corrected, but the commit
message was not.
